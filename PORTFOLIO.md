# Landing page pessoal

Os arquivos do site ficam em `docs/`. HTML, CSS e JavaScript sem etapa de build.

## Publicação

GitHub → Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.

Endereço previsto após a ativação: https://toled0o.github.io/Toled0o/

O README da raiz continua sendo a apresentação do perfil do GitHub. O GitHub Pages apresenta a landing page com navegação, projetos e demonstração interativa.

## Conteúdo e acessibilidade

- Formação e localização confirmadas pelo autor.
- Projetos Python públicos e painel apresentado como projeto em desenvolvimento.
- Dados financeiros ilustrativos identificados como fictícios.
- Rolagem nativa, indicador de leitura e animações que respeitam a preferência por movimento reduzido.
- O conteúdo continua disponível sem JavaScript; a demonstração interativa e a cópia de e-mail usam JavaScript.
- Formulário processado no navegador, sem coleta ou envio das notas.

## Editar

- `docs/index.html`: conteúdo e links.
- `docs/styles.css`: aparência e comportamento responsivo.
- `docs/app.js`: demonstração de notas, cópia de e-mail e acompanhamento da leitura.

Sirva a pasta `docs` com um servidor HTTP local para pré-visualizar. Não publique bancos, backups, arquivos de clientes ou credenciais neste repositório.
