Gerenciador financeiro

Um programa usado pelo terminal para registrar entradas e saídas de dinheiro. Ele organiza os gastos por categoria, calcula o saldo do mês e salva os registros para a próxima consulta.

O que estou estudando: organização de dados, funções e leitura e escrita de arquivos.

PythonArquivos JSON
Ver um exemplo e os próximos passos +
Exemplo de relatório · dados fictícios

DespesasR$ 450,00

Como funciona

Os registros podem ser cadastrados, consultados e removidos. O resumo mensal mostra o total de receitas, despesas e o saldo.

Próximos passos de estudo

Aprender a testar os cálculos, melhorar a validação dos valores digitados e revisar a precisão das operações com dinheiro.
